## Update to `0.4` For `mdBook` `5.x`

`mdbook-journal` has been updated to `0.4` with support for `mdBook` version
`5.x`.  Any version from `5.0.0` to `5.2.0` is supported as of this writing.
If you attempt to use an earlier version of the journal with the newer
`mdBook` you will receive an error message.
